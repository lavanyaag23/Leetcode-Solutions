# 🌐 Graphs

This folder contains solutions to **LeetCode Graph problems** implemented in **Java**.

Graph problems are essential for coding interviews and competitive programming. They help build a strong understanding of graph traversal, connectivity, shortest paths, cycle detection, and efficient query processing.

---

## 📚 Topics Covered

* Graph Traversal
* Depth-First Search (DFS)
* Breadth-First Search (BFS)
* Connected Components
* Complete Graph Detection
* Union Find (Disjoint Set Union)
* Graph Connectivity
* Path Existence Queries
* Directed Graphs
* Cycle Detection
* Graph-Based Dynamic Programming
* Query Processing
