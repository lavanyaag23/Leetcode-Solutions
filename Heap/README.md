# 📚 Heap

This folder contains solutions to **LeetCode Heap problems** implemented in **Java**.

Heaps are important data structures used for efficiently maintaining the minimum or maximum element. These problems cover priority queues, min-heaps, max-heaps, median maintenance, and efficient data processing techniques commonly used in coding interviews.
